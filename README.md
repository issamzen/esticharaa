# Expert Insights Hub

Build a complete production-ready SaaS platform called "Estichara.ma".



PROJECT OVERVIEW



Estichara.ma is a modern Moroccan question-and-answer marketplace where users can ask questions in any category and receive answers from professionals or people with real-life experience.



The platform uses a token economy.



MAIN BUSINESS MODEL



1. User purchases token packs.

2. User spends tokens to:

   - Ask premium questions

   - Unlock full answers

   - Contact experts

3. Experts earn tokens by providing approved answers.

4. Experts can convert tokens into cash once they reach a configurable payout threshold.

5. Users can only see:

   - Question title

   - First 2 lines of answer

   - Expert profile

   - Ratings

6. Full answer is locked.

7. User must spend tokens to unlock and view complete answer.
